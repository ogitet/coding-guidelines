---
title: 準拠レベル
description: 各ルールに付ける準拠レベル（必須・推奨・任意）の意味と、ルールから外れるときの扱い。
---

この規約のルールには、必須・推奨・任意のいずれかの準拠レベルを付けています。準拠レベルは、そのルールから外れてよいかどうかと、外れるときに何をするかを表します。

| レベル | 付けるルール | 外れるとき |
| :-- | :-- | :-- |
| 必須 | 守らないと、不具合や保守しにくいコードに直結するもの | ライブラリの制約などで、技術的に守れない場合だけ外れます。理由を該当箇所のコメントに書きます |
| 推奨 | 守ったほうがよいが、状況によっては別の書き方がよいこともあるもの | 守らないほうがよい理由があれば外れます。理由をコメントかプルリクエストに書きます |
| 任意 | どちらの書き方でも品質に差が出にくく、統一することに価値があるもの | 採用するかをプロジェクトごとに決めます。理由は書きませんが、同じプロジェクトの中では書き方を統一します |

必須のルールから外れるときは、次のようにコメントに理由を書きます。

```ts
// 規約の例外（any を使わない）：ライブラリの型定義が誤っており、any でしか受け取れないため
```

AIにコードを書かせるときも同じ準拠レベルを適用し、必須・推奨のルールから外れた場合は、外れたルールと理由を報告させます。
