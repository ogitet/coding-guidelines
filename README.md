# coding-guidelines

個人用コーディング規約サイト。Astro Starlight で構築し、GitHub Pages で公開する。

## コマンド

| コマンド          | 内容                                     |
| :---------------- | :--------------------------------------- |
| `npm install`     | 依存パッケージをインストールする         |
| `npm run dev`     | 開発サーバーを起動する（localhost:4321） |
| `npm run build`   | `./dist/` に本番用サイトを出力する       |
| `npm run preview` | ビルド結果をローカルで確認する           |

規約本文は `src/content/docs/` 以下のMarkdownで管理する。
